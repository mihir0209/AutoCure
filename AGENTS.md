# Swarm RSI Agent Guidelines: Elephant-Goldfish Model (EGM) Integration

All autonomous swarm agents operating in this repository must strictly adhere to the Elephant-Goldfish Model (EGM):
1. **Elephant Context**: Hold deep institutional knowledge, architecture invariants, and state continuity.
2. **Goldfish Review**: All architectural specifications, threat models, and security sentinels must undergo zero-context antagonistic scrutiny before code synthesis.
3. **Document Standards**: Use EGM standards located in `.agents/resources/document_standards/` for feature specifications, implementation readiness, and regression analysis.
4. **Skills Active**: `egm_review_loop`, `egm_review`, `egm_draft`, `egm_resolve`, and `egm_drift_report`.
